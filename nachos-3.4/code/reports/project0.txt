Part a) I connected to Nachos machine with ocelot and I did so with my laptop, which is a 2020 MacBook Pro with a Intel Core i5 and x86_64 ISA. I followed the installation steps from Luis Useche's PDF guide that was provided. To be more specific, I unpacked the Nachos zip, verified that the make and gcc were in my path along with LD_LIBRARY_PATH including /usr/local/lib and compiled with make in the code directory. Thankfully there were no errors in my compilation.

Part b) I ran the threads demo and my output matched exactly the expected pattern where the threads 0 and 1 alternate that looped 4 times and after that, Nachos detected that there were no runnable threads and stopped the program. After this I ran the program inside userprog and it also ran succesfully but in this program it printed that my machine was halting along with a summary of 22 ticks where 10 were the system and the other 12 were the user. Lastly, I ran the same program in single step mode and it ran successfully and printed the MIPS registers.

Part c) The Thread class makes a single thread of control and it has several operations like Fork, which creates a new thread, Finish, which cleans up the forked procedure when completed, Yield, which gives up the CPU while staying runnable, and Sleep, which suspends the CPU while blocked and is given the ability to wake up later. Each thread keeps track of a status as well as its own execution stack that's allocated by StackAllocate when Fork is called. Scheduler::Run operates in a different thread's context. Several more functions and variables are in this program.
